# 🎬 Top 450 Movies — Data Analysis

## 📌 Project Overview
Analysis of Top 450 movies ranked by IMDb, 
Rotten Tomatoes and Letterboxd ratings.

## 🛠️ Tools Used
- Microsoft Excel
- Power Query (data cleaning)
- Pivot Tables
- Excel Charts

## 📊 Dataset
Source: Kaggle — Top 500 Movies Ranked 
by IMDb, Rotten & Letterboxd
Records: 450 films after data cleaning

## 🔍 Key Questions
- Which decade produced the highest rated films?
- What is the most common genre?
- Where is the biggest gap between critics 
  and audience?

## 💡 Key Findings
- 1990s had highest average IMDb rating (8.19)
- Drama is the most common genre
- Fight Club has biggest gap: audience rates 
  21pts higher than critics
- 2010s produced the most top-rated films (115)
- WAR genre has highest average IMDb (8.14)
